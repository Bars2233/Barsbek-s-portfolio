# nutrition-data-scraper
Nutrition Data Scraper A Python-based web scraper designed to extract nutritional information (calories, proteins, fats, and carbohydrates) from the health-diet.ru portal.           Парсер данных о пищевой ценности Скрипт на Python для автоматического сбора данных о калорийности и составе продуктов (БЖУ) с сайта health-diet.ru.
